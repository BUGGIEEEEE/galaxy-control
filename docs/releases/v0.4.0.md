# v0.4.0 — Selective preflight and route evidence

## Verdict

`PACKAGE_READY`

This release makes path selection explicit without turning Galaxy Control into a generic executor:

- Doctor accepts the fixed targets `all`, `openminis`, `adb`, and `scrcpy`.
- OpenMinis tasks skip unrelated ADB and scrcpy checks.
- ADB tasks skip OpenMinis, scrcpy, and Tailscale checks.
- scrcpy tasks check ADB identity plus scrcpy availability.
- Enrollment requires a physically connected USB Galaxy, while remote ADB doctor checks accept a
  reviewed Tailscale transport only after reading and matching the enrolled physical serial and
  model.
- Successful preflight may be reused only in the current agent session; live readiness is not
  persisted and invalidation events are returned in the result.
- OpenMinis, ADB, and scrcpy results include fixed controller, transport, role, and verification
  metadata inside the existing result envelope.
- OmO Native receives an explicit runtime mapping and memory-only reuse policy.
- The public OpenMinis wrapper remains free of per-call quarantine scanning or repair.

Release evidence:

- `182 passed` in one full pytest run.
- Ruff check and format check passed.
- BasedPyright reported `0 errors, 0 warnings, 0 notes` for the main and bridge targets.
- Compileall and the history privacy scan passed with `0 findings`.
- On the enrolled Galaxy, OpenMinis action plus fresh observation, fixed remote ADB identity,
  read-only scrcpy start/stop, and scrcpy-to-OpenMinis cross-path observation passed.
- On the enrolled test environment, this unchanged public wrapper completed warm OpenMinis health
  calls in `0.57–0.70s`. A separate older customized installation measured `11.33–14.93s` because
  that local wrapper, which was never part of a public release, scanned runtime quarantine state
  before every command. The public `galaxy_control.sh` remains byte-identical to v0.3.1 with
  SHA-256 `d610914506688aa75e31e2b39e18556958252360c0adae9f79f15101079581bc`.

A second user's real Galaxy installation remains a separate `PILOT_INSTALL_VERIFIED` gate.
