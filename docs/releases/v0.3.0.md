## Added

- Three privacy-clean integration diagrams in the GitHub README.
- Same-session replay and maximum-occurrence union checks for saved folder-picker `ui-dump` data.
- Manifest, item-level selection ledger, selected-count, and post-move progress validation.
- Explicit rules for remembered pages, layout changes, empty-folder removal, overlays, partial rows,

The new checkers cannot issue OpenMinis, ADB, scrcpy, subprocess, selection, or completion actions.
They validate saved local artifacts only. Session-specific app names, counts, folders, coordinates,
serials, IPs, tokens, and pairing codes are not included.
