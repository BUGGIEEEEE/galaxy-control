## Security boundary

- Public source contains no fixed Galaxy or Mac peer address.
- The builder accepts no arbitrary host, IP, port, token, shell command, or bridge argv.
- Personalized files are written only into a new `0700` directory with `0600` contents.
- The Galaxy installer validates size, SHA-256, ownership, link count, manifest, and approval binding.
- The runtime exposes fixed OpenMinis actions only and every subprocess uses `shell=False`.
- The bridge token is generated on the Galaxy and is never returned.
- Existing OpenMinis app/APK and app data are not installed, updated, reconciled, or deleted.

## Live verification status

The existing maintainer Galaxy path was previously verified, but this new generalized bridge
installer has not yet completed a second-user Galaxy pilot. Therefore this release does not claim
`PILOT_E2E_VERIFIED` or `DISTRIBUTION_READY`.

The next pilot must prove: generated artifact installation through Minis, exact lifecycle `status`,
Mac `health`, Accessibility status, one harmless action, independent verification, stop, and
reconnect on the second user's own Mac and Galaxy.
