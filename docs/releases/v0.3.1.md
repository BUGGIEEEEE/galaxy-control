# v0.3.1 — Artifact evidence boundary clarification

## Verdict

`PACKAGE_READY`

This patch keeps the tested v0.3.0 implementation and makes its evidence boundary explicit:

- One UI inventory `replay` and `union` do not control the Galaxy, but they do create the explicitly
  named new Mac output directory.
- Ledger `check` reads its input TSV files without writing an output artifact.
- The capture-session label, selected count, and progress proof flags originate in external
  observations. The checkers validate consistency; they do not authenticate current Galaxy state.
- A successful checker result must not replace the normal pre-observation, minimum action, and
  independent post-verification loop.

The automated code, packaging, static, privacy, clean-install, and visual gates remain green. A
second user's real Galaxy installation and end-to-end control remain separate
`PILOT_INSTALL_VERIFIED` and `PILOT_E2E_VERIFIED` gates.
